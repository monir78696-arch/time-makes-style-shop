Free publishing with GitHub Pages:
1. Sign in/create account at https://github.com
2. Create a Public repository named time-makes-style
3. Upload index.html and the images folder (keep all three image files inside images/)
4. Open Settings > Pages
5. Select Deploy from a branch, branch main, folder /(root), then Save
6. Wait for GitHub Pages to display your public website link.
